# Сертификат проверки застройщика

Веб-приложение для проверки застройщика по 13 блокам (всего 50 баллов). Результат выпускается как сертификат из отдельных листов A4, а все сертификаты хранятся в реестре. Макет формы взят из `Сертификат_проверки_застроищика_2.pdf`.

Откройте `index.html` в браузере — сервер и сборка не нужны.

## Разделы

| Раздел | Адрес | Что делает |
|---|---|---|
| Новая проверка | `#/` | Форма из 13 блоков, живой подсчёт баллов, проверка полей |
| Реестр | `#/admin` | Все выданные сертификаты: поиск, фильтры, статистика, действия |
| Сертификат | `#/cert/<id>` | Просмотр листов A4, печать и сохранение в PDF |
| Изменение | `#/edit/<id>` | Правка выпущенного сертификата, сохраняется как новая редакция |
| Проверить | `#/verify` | Проверка подлинности по номеру и контрольному коду |

## Форма

- Статус каждого блока выбирается кнопками: **Подтверждено / С замечаниями / Риск**.
- **Навигация по блокам** закреплена сверху: номера 1–13 окрашиваются по статусу, у заполненных блоков стоит точка, у блоков с ошибками — красная рамка.
- **Нижняя панель** показывает процент заполнения обязательных полей и кнопку выпуска (или `Ctrl/⌘ + Enter`).
- Кнопка **«Авто»** присваивает следующий свободный номер `ПЗ-ГГГГ-NNN`. Занятый номер выпустить нельзя.
- **Рекомендация по баллам** подставляется одной кнопкой.
- **Черновик** сохраняется автоматически.
- **Ошибки при выпуске:** форма сама прокручивается к первой ошибке, а общий список ведёт к каждому полю.

## Сертификат (A4)

- Каждый лист — отдельная страница **210 × 297 мм** со своей рамкой, колонтитулом (номер сертификата), нумерацией «Лист N из M» и контрольным кодом.
- Содержимое раскладывается по листам автоматически:
  - лист 1 — титул, итог и сводная таблица;
  - со второго листа — подробные результаты по блокам;
  - последний лист — заключение, реквизиты, подпись и М.П.
- Длинный блок переходит на следующий лист с пометкой «продолжение», заголовки разделов не остаются внизу листа в одиночестве.
- На экране листы масштабируются под ширину устройства, при печати выводятся в натуральную величину.
- **«Печать / PDF»** → «Сохранить как PDF»: получается PDF, где каждый лист — отдельная страница. Пример — `example-certificate.pdf`.

## Реестр (админка)

- Статистика: всего выдано, средний балл, распределение по уровням надёжности.
- Поиск по номеру, застройщику, ИНН, проекту и контрольному коду; фильтры по уровню и статусу; сортировка.
- Действия: открыть, изменить (новая редакция), создать копию, аннулировать или восстановить (на листах появляется водяной знак «Аннулирован»), удалить.
- Экспорт в JSON (резервная копия и перенос между браузерами), экспорт в CSV (открывается в Excel), импорт из JSON.

> Реестр хранится в `localStorage` этого браузера. Чтобы с ним работали несколько сотрудников и проверка подлинности была доступна всем, нужен сервер с базой данных; формат записей для этого уже готов (см. `js/store.js`).

## Подсчёт баллов

| Статус | Баллы |
|---|---|
| Подтверждено | полный вес блока |
| С замечаниями | половина веса |
| Риск | 0 |

Уровни: **40–50** — высокий, **25–39** — средний, **менее 25** — низкий.

Дополнительные правила:

- Риск по блоку 12 всегда даёт низкий уровень.
- Риск по блоку 9 или 11 даёт уровень не выше среднего.
- Статус «Подтверждено» в блоке 12 можно поставить только при всех отмеченных обязательных документах.

## Файлы

- `index.html` — разметка;
- `styles.css` — оформление, анимации, адаптив, правила печати A4;
- `js/core.js` — описание блоков, подсчёт баллов, форматирование;
- `js/store.js` — реестр и черновик;
- `js/certificate.js` — сборка сертификата и раскладка по листам A4;
- `js/admin.js` — реестр и проверка подлинности;
- `js/app.js` — форма, проверка полей, маршрутизация, уведомления.
